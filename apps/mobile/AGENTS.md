# DeepTutor Mobile 本地验收

1. 在独立体验工作树里开发。可以创建本地 Git 提交来记录进度和支持回滚。
2. 运行自动化测试，用 `Start-DeepTutor-Mobile.cmd` 启动 Android 体验环境。向用户交代可体验的改动、测试结果和已有缺口。
3. 由用户在本机亲自体验。根据反馈修改后，重新测试并交给用户复验，直到用户明确确认验收通过。
4. 只有用户明确验收并明确授权相应的 GitHub 操作后，才执行推送、创建或更新 PR、合并。自动化测试和代理自测不能代替用户验收。

## 产品原则

让对话成为主要入口，保持操作简单直观。根据移动端场景设计界面，高级功能默认折叠。可以自动完成的操作尽量交给 Agent，底层的复杂性由系统承担。
